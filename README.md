1. PROJECT OVERVIEW
--------------------------------------------------
This project demonstrates the capture and analysis of network traffic using 
Wireshark on a Windows operating system. The objective was to observe and 
analyze DNS communication, TCP three-way handshake behavior, HTTP traffic, 
and identify any abnormal or suspicious packets within the captured data.

The analysis was performed using real-time traffic generated through command 
line utilities and web browsing activities.

==================================================

2. PROJECT OBJECTIVES
--------------------------------------------------
- Capture live network traffic using Wireshark
- Analyze DNS query and response packets
- Identify and examine the TCP three-way handshake
- Capture and analyze HTTP GET requests and responses
- Detect any malformed or suspicious packets

==================================================

3. TOOLS AND ENVIRONMENT
--------------------------------------------------
Operating System:
- Microsoft Windows

Tools Used:
- Wireshark
- Command Prompt (nslookup, ping)
- Web Browser

==================================================

4. TRAFFIC GENERATION METHODS
--------------------------------------------------
The following commands were executed to generate network traffic:

nslookup google.com
ipconfig /flushdns
ping google.com

HTTP traffic was generated by accessing:
http://example.com

These actions produced DNS, ICMP, TCP, and HTTP packets for analysis.

==================================================

5. WIRESHARK FILTERS USED
--------------------------------------------------
The following display filters were applied during analysis:

dns
dns.flags.response == 0
dns.flags.response == 1
tcp.flags.syn == 1
http
tcp.analysis.flags
quic

These filters were used to isolate specific protocols and packet types.
